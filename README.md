## About Me

I am a software engineer with a dual focus: I build massive, high-availability web platforms, and I engineer technical tools for 3D production pipelines. 

**For Web & Software Engineering:** I specialize in robust backend architectures and distributed systems. With a strong foundation in Python (Django/FastAPI), React/Next.js, and PostgreSQL, I have architected digital publishing platforms supporting over 180,000 monthly active users and built AI-driven orchestration systems for dynamic workload balancing.

**For CG & Pipeline Engineering:** I build tools that help artists work faster. Leveraging Python, C++, Qt, and procedural systems, I engineer desktop applications and custom pipeline utilities for Maya, Houdini, and USD workflows, focusing on clean UI architecture and performance-first execution.

## 🎬 CG Pipeline & Desktop Tools

### [Maya SceneQC](https://github.com/ok-elawady/maya-scene-qc)  
**Python / PySide / Maya / AI Vision Models**  
AI-powered asset validation tool for Autodesk Maya bridging deterministic pipeline checks with multimodal AI visual review to enforce production standards.

### [FrameCore](https://github.com/ok-elawady/FrameCore)  
**C++ / Qt6 / Desktop UI**  
High-performance desktop application built with C++ and Qt6, focused on fast interaction and clean UI architecture for monitoring farm workloads.

### [ArchSun](https://github.com/ok-elawady/ArchSun)  
**Python / PySide / Maya / Arnold**  
Procedural daylight setup tool for Autodesk Maya generating physically accurate Arnold lighting rigs using real-world geolocation data.
